# QsSim
A Bootleg Qs Simulator for BA

1. Break the force by clicking anywhere on the screen
2. Try to click the ladder in just 1 tick

Current features include:
- Lots of camera angles, but only the default one supports ladder clickboxes
- Highlighting the ladder
- Your choice of using only destination qs spawn tiles or all spawn tiles

Future features include:
- Branches
- Wave 3
- More clickboxes for different camera angles
- Client ticks if those are important
